RGB Features

+

LiDAR Features

↓

Concatenate

↓

MLP

↓

Driving

This is called early feature fusion.

It works...

But it's actually a very weak way to combine information.

Suppose RGB says

"There is a pedestrian."

LiDAR says

"There is an obstacle."

Distance = 7.8m

If we simply concatenate them:

[RGB Features | LiDAR Features]

the network has to learn the relationship indirectly.

Instead, the transformer asks questions like:

RGB Feature #142

↓

Which LiDAR features
are important to me?

↓

Attention

↓

Fuse only relevant information

That is cross-attention.

Instead of blindly mixing everything, it learns what should interact with what.

Imagine:

Person B
